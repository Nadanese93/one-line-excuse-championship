A single-line excuse an AI agent gives its human when something goes wrong.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes `entry.txt` into the output directory: one line of UTF-8 text,
1 to 140 characters, no trailing newline.
